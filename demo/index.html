Papaya Assist -- Demo

An embeddable AI chatbot powered by RAG. Open this page in a browser to see the widget in action.

How to embed

Add the following snippet before </body> on any page:

<script
  src="https://your-widget-host/chatbot-widget.min.js"
  data-stream-url="YOUR_STREAM_URL"
  data-tenant-id="YOUR_TENANT_ID"
  data-title="Chat with us"
  data-primary-color="#4f46e5">
</script>

Replace YOUR_STREAM_URL and YOUR_TENANT_ID with the values from your deployment. See the README for full configuration options.

Live preview

The chat bubble should appear in the bottom-right corner of this page. It uses the local widget file with placeholder endpoints, so sending messages will fail until you configure real URLs.
